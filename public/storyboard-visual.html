🏗️ MODUL 3: KOMPONEN INTERNAL & KERNEL SISTEM OPERASI Arsitektur Monolithic vs Microkernel
1. Kernel Mode vs User Mode 2. CPU Scheduler 3. Memory Manager 4. File System 5. Device Drivers
🛡️ Mode Dual-Operasi (Ring 0 & Ring 3)
Sistem operasi modern memisahkan hak akses ke dalam dua ring keamanan:
• User Space (Ring 3): Aplikasi umum berjalan dengan proteksi terbatas.
• Kernel Space (Ring 0): Inti OS memiliki akses langsung tanpa batas ke register CPU & hardware.
⚖️ Monolithic vs Microkernel
• Monolithic (Linux, Windows NT): Semua driver & servis berada di kernel demi kecepatan maksimal.
• Microkernel (Minix, QNX): Hanya fungsi esensial di kernel; driver berjalan di user mode demi stabilitas.

  • Struktur Tab Interaktif: 5 pilihan tab komponen inti di bagian atas.
